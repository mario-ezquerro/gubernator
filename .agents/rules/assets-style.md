# Rule: Assets and Styling Guidelines

## Objective
To ensure visual consistency and branding across the Gubernator project.

## Requirements

1. **Brand Icon:** The official icon for the project is `gubernator-icon.png`. You MUST use this image in the `README.md` and anywhere else a logo or icon is needed (e.g., in future Web UIs or generated designs).
2. **Typography:** If you generate CSS, Web UIs, or any visual components, you MUST use the **Roboto** font. Do not use default fonts or other sans-serif alternatives without explicit instruction.
3. **Roman Theming:** Maintain the Roman Empire thematic colors and styles (e.g., strong reds, gold, marble whites) if designing any UI, while keeping the UX modern and premium.
